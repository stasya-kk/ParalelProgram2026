# Лабораторная работа №1
## Умножение квадратных матриц

---

### 1. Задание

Написать программу на языке C++ для перемножения двух квадратных матриц.

**Требования:**
- Исходные данные: файлы, содержащие значения исходных матриц (В моей работе они генерируются самостоятельно на языке Python)
- Выходные данные: файл со значениями результирующей матрицы, время выполнения программы, объем задачи (количество элементов, объем памяти, количество операций)
- Обязательно: автоматизированная верификация результатов вычислений с помощью стороннего ПО (Python / NumPy)

### 2. Цель работы

Исследовать зависимость времени умножения квадратных матриц от их размера, оценить производительность алгоритма и проверить корректность вычислений с помощью автоматизированной верификации.

### 3. Реализация 

Программа реализует классический алгоритм умножения матриц с тремя вложенными циклами. Этот алгоритм является прямым следствием математического определения произведения матриц. Математическая основа Произведение двух матриц A и B размером N×N определяется как: C[i][j] = Σ(k=1 to N) A[i][k] * B[k][j], где i, j, k принимают значения от 0 до N-1.

Временная сложность: O(N³) Объем вычислений: 2 * N³ операций, где: N³ операций умножения N³ операций сложения

### 5. Верификация результатов

Для автоматизированной проверки корректности вычислений использовался Python с библиотекой NumPy.

**Процесс верификации:**

2. Python скрипт читает те же матрицы A и B
3. NumPy вычисляет эталонное произведение: `C_numpy = A @ B`
4. Сравнение выполняется с помощью `np.allclose()` с точностью rtol=1e-6, atol=1e-8
