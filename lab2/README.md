## 1. Задание

Модифицировать программу из лабораторной работы №1 для параллельного выполнения с использованием технологии OpenMP.

**Требования:**
- Провести серию экспериментов с разным количеством потоков (1, 2, 4, 8)
- Провести эксперименты с матрицами разных размеров (200, 400, 800, 1200, 1600, 2000)
- Исследовать влияние количества потоков на производительность
- Выполнить автоматизированную проверку результатов

---

## 2. Реализация

В программу из лабораторной работы №1 были добавлены директивы OpenMP для распараллеливания вычислений:

```cpp
vector<vector<double>> multiplyMatricesParallel(const vector<vector<double>>& A, 
                                                 const vector<vector<double>>& B,
                                                 int num_threads) {
    int n = A.size();
    vector<vector<double>> C(n, vector<double>(n, 0.0));
    
    omp_set_num_threads(num_threads);
    
    #pragma omp parallel for collapse(2)
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            double sum = 0.0;
            for (int k = 0; k < n; k++) {
                sum += A[i][k] * B[k][j];
            }
            C[i][j] = sum;
        }
    }
    
    return C;
}
```

## 5. Анализ результатов

### 5.1. Корректность вычислений

Программа успешно распараллелена с помощью OpenMP. Время выполнения последовательной версии (1 поток) растет пропорционально кубу размера матрицы (O(N³)), что соответствует теоретической вычислительной сложности.

### 5.2. Ускорение

- Максимальное ускорение достигнуто для матрицы **2000×2000** при использовании 8 потоков — **7.79x**
- Для матриц большого размера (1600, 2000) ускорение близко к идеальному для 4 потоков (3.98x и 4.69x)
- Среднее ускорение: **1.85x** (2 потока), **3.59x** (4 потока), **5.41x** (8 потоков)

### 5.3. Эффективность

- Наилучшая эффективность наблюдается для матриц размером 800 и 2000 (до 1.17 для 4 потоков)
- При использовании 2 потоков средняя эффективность составляет **93%**
- При использовании 4 потоков — **90%**
- При использовании 8 потоков эффективность снижается до **68%** из-за накладных расходов на синхронизацию

### 5.4. Производительность

- Пиковая производительность достигнута для матрицы **1200×1200** при 8 потоках — **10.30 GFLOPS**
- Для малых матриц (200, 400) производительность ограничена накладными расходами
- Для больших матриц (1600, 2000) производительность стабилизируется на уровне 9-10 GFLOPS

## 6. Вывод

В ходе работы программа из лабораторной работы №1 успешно модифицирована для параллельной работы с использованием OpenMP.

**Основные результаты:**
- Корректность результатов подтверждена автоматизированной верификацией
- Максимальное ускорение: **7.79x** (матрица 2000×2000, 8 потоков)
- Пиковая производительность: **10.30 GFLOPS** (матрица 1200×1200, 8 потоков)
- Наилучшая эффективность достигается при использовании 2-4 потоков (93-90%)
- Чем больше размер матрицы, тем выше абсолютный выигрыш от распараллеливания

OpenMP позволяет эффективно использовать многоядерные процессоры для задачи умножения матриц. Дальнейшее увеличение числа потоков (более 8) может быть нецелесообразно из-за роста накладных расходов и снижения эффективности.
