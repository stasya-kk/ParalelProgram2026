# Лабораторная работа №5
## Параллельное умножение матриц с использованием MPI на кластере «Сергей Королёв»

### Цель работы
Изучить основы параллельного программирования с использованием MPI, освоить работу с системой пакетной обработки заданий SLURM на суперкомпьютере «Сергей Королёв», разработать и реализовать параллельную программу умножения матриц.

### Задачи работы
- Освоить основные команды SLURM для управления заданиями
- Научиться создавать скрипты для пакетной отправки заданий
- Разработать параллельную программу умножения матриц на C++ с использованием MPI
- Реализовать распределение вычислений между несколькими процессами
- Протестировать программу на матрице размером 500×500
- Проанализировать полученные результаты и оценить эффективность параллелизации

### Методика проведения экспериментов

#### Среда выполнения
- **Кластер:** СК «Сергей Королёв» (Самарский университет)
- **MPI:** Intel MPI
- **Компилятор:** mpicxx с флагом -O3
- **Система пакетной обработки:** SLURM

#### Параметры экспериментов
- Размер матрицы: **500×500**
- Количество процессов: **1, 2, 4, 8**
- Количество повторений: 1 для каждой комбинации

#### Компиляция программы

```bash
# Загрузка необходимых модулей
module load intel/mpi4

# Компиляция с оптимизацией
mpicxx -O3 -o lab5_mpi mpi_matrix_mult.cpp

# Проверка успешности компиляции
ls -la lab5_mpi

# Отправка задания в очередь
sbatch run_complete.slurm

# Просмотр статуса задания
squeue -u 2024-01376

# Номер задания: 260944
```

### Анализ результатов

#### Анализ ускорения

При увеличении количества процессов с 1 до 8 ускорение составило **6.93x**, что близко к идеальному линейному ускорению (8x). Отклонение от идеала составляет около 13%.

**Наблюдения:**
- При переходе с 1 на 2 процесса: ускорение 1.99x (почти идеальное)
- При переходе с 2 на 4 процесса: ускорение 3.92x (почти идеальное)
- При переходе с 4 на 8 процессов: ускорение 6.93x (небольшое снижение)

#### Анализ эффективности

Эффективность параллелизации на 8 процессах составила **86.6%**.

**Факторы, влияющие на снижение эффективности:**
1. **Накладные расходы на коммуникацию** — передача данных между процессами
2. **Синхронизация процессов** — ожидание самого медленного процесса
3. **Неравномерное распределение нагрузки** — остаток от деления (500 / 8 = 62.5, нецелое число)

#### Сравнение с идеальным ускорением

| Процессов | Идеальное ускорение | Реальное ускорение | Потери |

| 2 | 2.00x | 1.99x | 0.5% |
| 4 | 4.00x | 3.92x | 2.0% |
| 8 | 8.00x | 6.93x | 13.4% |
