# Лабораторная работа №3
## Параллельное умножение матриц с использованием MPI

---

### Цель работы

Модифицировать программу из лабораторной работы №1 для параллельной работы по технологии MPI. Провести серию экспериментов с разными размерами матриц и разным количеством процессов, исследовать влияние количества ядер на производительность.

---

### Реализация

Программа выполняет блочное распределение строк матрицы A между процессами. Каждый процесс вычисляет свою часть строк результирующей матрицы C, после чего результаты собираются на процессе 0.

### Анализ результатов

**Время выполнения:**
- Для всех размеров матриц время уменьшается при увеличении числа процессов
- Максимальное сокращение для 400×400: с 0.0171 с до 0.0039 с (в 4.33 раза)
- Для 2000×2000 время сократилось с 3.81 с до 2.07 с

**Ускорение:**
- Максимальное ускорение: **4.33x** (матрица 400×400, 8 процессов)
- Для малых матриц (200) ускорение незначительное из-за накладных расходов MPI
- Для средних и больших матриц ускорение стабильное

**Эффективность:**
- Максимальная эффективность: **94.3%** (матрица 800×800, 2 процесса)
- С увеличением числа процессов эффективность снижается
- Для 8 процессов эффективность падает до 16–54%

**Производительность:**
- Максимальная производительность: **32.50 GFLOPS** (матрица 400×400, 8 процессов)
- Для большинства размеров 8 процессов дают максимальную производительность

---

### Верификация

Для каждой комбинации (размер × количество процессов) выполнена проверка корректности умножения путём сравнения с эталонным результатом NumPy.

**Результат:** Все 24 теста (6 размеров × 4 варианта процессов) прошли верификацию успешно.
